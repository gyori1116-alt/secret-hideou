# 📄 알PDF

2D 픽셀 실시간 멀티플레이 마을 게임. 브라우저 링크 하나로 접속해서 함께 돌아다니고, 집을 짓고, 농사·낚시·목장·사냥·요리를 하고, 말풍선으로 대화해요.
브라우저 탭에는 **알PDF**라고 표시되고, 상대가 채팅을 보냈는데 아직 안 봤으면 탭 제목이 `💬 새 메시지 N개`로 깜빡여요.

## 지도

| 지역 | 위치 | 할 수 있는 것 |
|---|---|---|
| 🏠 마을 | 왼쪽 위 | 상점, 퀘스트 게시판, 📌 마을 게시판(한가운데), 텃밭, 동물 우리, 연못 |
| 🏡 집 짓는 땅 | 마을 오른쪽 + 가운데 들판 | 넓은 빈 풀밭. 마음껏 집을 지어요 |
| ⛏ 동굴 | 맨 아래 왼쪽 | 어두워요(횃불로 밝혀요). 돌·철광석·금광석·수정, 동굴 호수 낚시 |
| 🌲 나무꾼의 숲 | 맨 아래 오른쪽 | 나무·소나무 베기, 버섯·산딸기 따기, 사슴·멧돼지, 송어·연어 낚시, 모닥불 요리 |

(나무·바위는 다시 자라서 생산 구역은 크지 않게, 맨 아래에 모았어요. 동굴과 숲은 안쪽 굴로도 이어져요.)

오른쪽 위 **미니맵**에 내 위치가 빨간 원으로, 다른 사람은 옷 색깔 점으로 보여요. 미니맵을 누르면 커지고, M 키로 숨겨요.

## 할 수 있는 것

| 기능 | 방법 |
|---|---|
| ⭐ 레벨 | 수확·낚시·채집·요리·사냥·퀘스트로 경험치. 초반엔 빨리, 갈수록 많이 필요해요 (Lv1→2: 20, Lv10→11: 796). 왼쪽 위 Lv 버튼으로 레벨 보상 보기 |
| 🔓 레벨 해금 | 레벨마다 새 씨앗·동물·펫·가구·옷·요리법이 상점·요리·만들기에서 열려요. Lv.10 → 가방 45칸·큰 상자(54칸), Lv.20 → 가방 54칸, 5레벨마다 펫 수 +1 |
| 📌 마을 게시판 | 📢 업데이트 소식(자동 공지) / 📝 건의함(누구나 글·👍) / 🏅 금주의 MVP |
| 🏅 금주의 MVP | 💰 부자(판매 수익) · 🏆 퀘스트(깬 수) · 🌾 장인(수확·낚시·요리). 일요일 0시 발표, 1~3등 우편함 상품, 1등은 일주일 동안 이름 옆 👑 |
| 📮 우편함 | 퀘스트 창 맨 위. MVP 상품, 예전에 못 받은 보상, 지도 변경으로 옮겨진 상자 속 물건 |
| 🍽️ 올려놓기 | 조리대·싱크대·테이블·책상·협탁·서랍장 위에 그릇 선반·양념 선반·전자레인지·커피머신·밥솥·어항·촛대 등을 올려요. 올린 전자레인지·밥솥으로 요리 가능. X는 위에 올린 것부터 회수 |
| 🏠 건축 | 벽 20종·바닥 25종·문 2종. 🔨 만들기나 상점에서 구해서 Space로 놓고 X로 회수 |
| 🛋️ 가구 | 거실·주방·욕실 가구 60여 종. 의자·소파·변기는 E로 **앉고**, 침대·욕조는 E로 **눕고**, TV·컴퓨터·스탠드·샤워기·세탁기는 E로 **켜고 끄기** |
| ↻ 가구 회전 | 가구를 들고 R → 놓을 방향(앞·왼쪽·뒤·오른쪽) 바꾸기. 놓은 가구를 보고 R → 그 자리에서 돌리기. 의자·소파·침대·TV·테이블 등은 진짜 옆모습·뒷모습으로, 나머지도 서 있는 모습으로 보여요 |
| 🐾 펫 | 강아지·고양이·토끼 등 여러 마리를 키워요. 따라다니는 건 1마리, 나머지는 집에서 지내요. 가방에 넣어도 이름을 기억해요 |
| 📦 상자 | 만들기(나무 8개)나 상점(💰40)에서 구해서 놓고 E로 열기. 27칸 보관, 칸을 누르면 옮기기, "모두 넣기/꺼내기". 주인은 🔒 잠금 가능. 빈 상자만 X로 회수 |
| 🍳 요리 | 가스레인지·전자레인지·모닥불·벽난로 앞에서 E → 요리 17종. 요리를 들고 Space로 먹으면 30초 동안 빨라져요 |
| 📖 도감 | 낚시·농사·요리·사냥·목장·광석·채집 도감. 처음 얻으면 등록되고, 다 모으면 특별 보상 (K 키) |
| 📜 퀘스트 | 업적 46개 + 일간 3개(깨면 레벨이 올라 더 어려운 퀘스트가 바로 나와요) + 주간 4개 + 월간 3개. 깨면 받은 보상을 창으로 보여줘요 |
| ⏰ 초기화 | 한국 시간 기준: 일간은 매일 00시, 주간은 일요일 00시, 월간은 다음 달 1일 00시에 못 깬 퀘스트가 새로 바뀌어요 |
| ✨ 퀘스트 전용 | 피아노·벽난로·왕좌·황금 낚싯대·점박이 강아지·날개 등 수십 가지는 퀘스트·도감 보상으로만 얻어요 (상점에서 못 사고, 거래도 안 돼요) |
| 👗 꾸미기 | C 키: 머리 8종, 옷 13종, 머리 장식 22종, 등(날개·망토 등) 7종. 일부는 상점 🎀 꾸미기에서 사고, 일부는 퀘스트 보상 전용 |
| ✋ 손에 들기 | 단축바에서 고른 아이템이 캐릭터 손에 보여요 (다른 사람에게도) |
| 🤝 거래 | 오른쪽 접속자 목록의 🤝 버튼 → 상대가 수락하면 물건·코인을 올리고 둘 다 ✅ 확인하면 교환 |
| 🌱 농사 | 괭이로 물만 빼고 어디든(집 안 바닥, 길, 모래, 숲, 동굴) 밭을 갈 수 있어요. 바닥 블록은 가방으로 돌아와요 |
| 🎒 가방이 꽉 찼을 때 | 보상 받기·만들기·요리 버튼이 막히고 "가방을 비워야 받을 수 있어요"라고 알려줘요. 수확·낚시·채집·사냥도 넘쳐서 사라지지 않게 막아요 |
| 🎁 보상 | 퀘스트 보상은 주로 코인 + 경험치. 아이템은 가끔, 상점에서 못 사는 것만 (퀘스트 전용·광석·요리·만들기 전용) |
| 🎣 낚시 · 🐔 목장 · 🏹 사냥 | 예전과 같아요. 지역마다 잡히는 물고기가 달라요 |

## 조작법

| 키 | 하는 일 |
|---|---|
| WASD / 방향키 | 이동 |
| 1~9 / 마우스 휠 | 단축바 아이템 고르기 |
| Space / 왼쪽 클릭 | 고른 아이템 쓰기 (놓기, 밭 갈기, 물 주기, 낚시, 먹기) |
| E | 상호작용 (상점, 게시판, 문, 수확, 앉기·눕기, 켜기, 요리, 따기, 강아지) |
| X / 오른쪽 클릭 | 부수기·줍기·캐기 |
| R | 가구 돌리기 |
| I / C / Q / K | 가방 / 꾸미기 / 퀘스트 / 도감 |
| M | 미니맵 켜기·끄기 |
| Enter | 채팅 |
| Esc | 창 닫기, 낚시 그만 |

## 파일 구성

| 파일 | 역할 |
|---|---|
| `server.js` | 서버: 맵·동물·강아지·가방·코인·퀘스트·도감·거래를 관리하고 저장 |
| `public/shared.js` | 아이템, 가구, 상점, 만들기, 요리, 도감, 퀘스트, 아바타 목록과 맵 모양 |
| `public/draw.js` | 모든 픽셀 그림 (블록, 가구, 작물, 동물, 캐릭터, 움직이는 그림) |
| `public/client.js` | 게임 화면: 이동, 조작, 창들, 미니맵, 채팅, 탭 알림 |
| `public/index.html` | 화면 틀과 디자인 |

## 내 컴퓨터에서 실행

```bash
npm install
npm start
```

http://localhost:3000 을 열어요. 진행 상황은 `data` 폴더에 저장돼요.

## 인터넷에 올리기 (Render 무료) + 저장 설정

1. GitHub에 파일 올리기 (`node_modules`, `data` 폴더, `CODE.txt`는 빼고 — 저장소 비밀 키가 들어 있어요).
2. render.com → New → Web Service → 저장소 선택
   - Build Command: `npm install` / Start Command: `npm start` / Instance Type: `Free`
3. Environment Variables:
   - `ROOM_CODE` = 비밀 코드 (선택)
   - `UPSTASH_REDIS_REST_URL`, `UPSTASH_REDIS_REST_TOKEN` = Upstash 값 (**꼭 추천**)
4. Render 로그에 `☁️ Upstash 클라우드에 저장해요`가 보이면 성공. 서버는 15초마다, 그리고 꺼질 때 저장해요.

> 무료 Render는 15분 동안 아무도 없으면 잠들어요. 다음 첫 접속 때 30~60초 기다리면 깨어나요.

## 업데이트와 데이터 (v2)

- 저장 이름(`hideout:world`, `hideout:profiles`)은 그대로라서 지은 집·가방·코인·퀘스트 기록이 그대로 이어져요.
- 예전 맵(64×48)으로 처음 켜지면 마을은 그대로 두고 숲·들판·동굴만 붙여서 100×112로 넓혀요. 이때 예전 맵은 `world_backup_v3`, 업데이트 전 프로필은 `profiles_backup_v4` 라는 이름으로 따로 보관해요.
- 마을 아래쪽·오른쪽 가장자리 나무 일부는 길목을 내려고 치워져요.

## 고쳐보기 쉬운 곳 (`public/shared.js`)

- **`UPDATES`: 업데이트 소식** — 새 업데이트를 할 때 맨 앞에 `{ v, date, title, items }`를 하나 추가하면, 서버가 켜질 때 채팅으로 공지하고 게시판 버튼에 N 표시가 떠요
- `SHOP_TABS`의 세 번째 숫자: 그 아이템을 살 수 있는 레벨 / `COOK`·`RECIPES`·꾸미기의 `lv`: 해금 레벨 / `expToNext`: 레벨업 경험치 / `EXP`: 활동 경험치
- `PRICE_MULT`: 상점 사는 가격 배수 (지금 2배) / `SHOP_TABS`: 상점 탭·물건·기본 가격 / `RECIPES`: 만들기 재료 / `COOK`: 요리 재료
- `QUESTS`: 업적 퀘스트 / `PQ_TEMPLATES`: 일간·주간·월간 퀘스트 종류 / `WEEKLY_POOL`, `MONTHLY_POOL`: 보상
- `COLLECTIONS`: 도감과 완성 보상 / `ACCESSORIES`, `TOPS`, `BACKS`: 꾸미기 (price = 상점, quest = 보상 전용)
- 아이템에 `questOnly: 1`을 붙이면 퀘스트 보상 전용(상점·거래 불가)이 돼요
- 탭 이름은 `public/index.html`의 `<title>`과 `public/client.js`의 `BASE_TITLE`
