# 🏠 비밀 아지트

2D 픽셀 실시간 멀티플레이 마을 게임. 브라우저 링크 하나로 접속해서 함께 돌아다니고, 집을 짓고, 농사·낚시·목장·사냥을 하고, 말풍선으로 대화해요.
브라우저 탭에는 **알PDF**라고 표시되고, 상대가 채팅을 보냈는데 아직 안 봤으면 탭 제목이 `💬 새 메시지 N개`로 깜빡여요.

## 할 수 있는 것

| 기능 | 방법 |
|---|---|
| 🏠 건축 | 나무를 베어(X) 가방의 🔨 만들기에서 벽·바닥·문·창문·울타리를 만들고 Space로 놓기. X로 다시 회수 |
| 🛣️ 길·표지판 | 흙길·돌길·벽돌길을 깔고, 표지판을 세우면 글씨를 쓸 수 있어요 (E로 수정) |
| 🛋️ 집 꾸미기 | 바닥 타일, 러그, 소파, 침대, 책장, 화분, 곰인형, 가로등 |
| 🌱 농사 | 괭이로 밭 갈기 → 씨앗 심기 → 물뿌리개로 물 주기(단계마다) → 다 자라면 E로 수확 |
| 🎣 낚시 | 낚싯대를 들고 물을 보고 Space → 찌에 ❗가 뜨면 바로 Space |
| 🐔 목장 | 상점에서 닭·양·소를 사서 풀어주고, 작물을 들고 Space로 밥 → 머리 위 선물(달걀·양털·우유)을 E로 받기. 울타리로 우리를 만들면 안에서만 놀아요 |
| 🏹 사냥 | 상점에서 활을 사서 Space로 쏘기 (마우스 쪽으로 조준). 토끼·멧돼지 → 고기·가죽 |
| 👗 아바타 | C 키: 피부, 머리 모양·색, 눈, 볼터치, 옷, 바지, 액세서리 |
| 📜 퀘스트 | Q 키: 16개 퀘스트, 보상으로 코인·아이템·액세서리 |
| 💰 상점 | 고양이 모모네 상점 앞에서 E: 씨앗·가구·동물·활 사기, 수확물·물고기 팔기 |

## 조작법

| 키 | 하는 일 |
|---|---|
| WASD / 방향키 | 이동 |
| 1~9 / 마우스 휠 | 단축바 아이템 고르기 |
| Space / 왼쪽 클릭 | 고른 아이템 쓰기 |
| E | 상호작용 (상점, 게시판, 표지판, 문, 수확, 동물) |
| X / 오른쪽 클릭 | 부수기·줍기 |
| I | 가방 (칸 자리 바꾸기, 만들기) |
| C / Q | 꾸미기 / 퀘스트 |
| Enter | 채팅 |
| Esc | 창 닫기, 낚시 그만 |

하얀 네모가 지금 손이 닿는 칸이에요. 마우스를 캐릭터 근처에 올리면 그 칸을 고를 수 있어요.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `server.js` | 서버: 맵·동물·가방·코인·퀘스트를 관리하고 저장 |
| `public/shared.js` | 아이템, 상점, 만들기, 작물, 동물, 퀘스트, 아바타 목록과 처음 맵 모양 (여기를 고치면 게임 내용이 바뀌어요) |
| `public/draw.js` | 모든 픽셀 그림 (블록, 가구, 작물, 동물, 캐릭터) |
| `public/client.js` | 게임 화면: 이동, 조작, 창(가방·상점·퀘스트·꾸미기), 채팅, 탭 알림 |
| `public/index.html` | 화면 틀과 디자인 |

## 내 컴퓨터에서 실행

```bash
npm install
npm start
```

http://localhost:3000 을 열어요. 진행 상황은 `data` 폴더에 저장돼요.
맵을 처음 상태로 되돌리려면 서버를 끄고 `data` 폴더를 지운 뒤 다시 켜면 돼요.

## 인터넷에 올리기 (Render 무료) + 저장 설정

1. GitHub에 파일 올리기 (`node_modules`, `data` 폴더는 빼고).
2. render.com → New → Web Service → 저장소 선택
   - Build Command: `npm install` / Start Command: `npm start` / Instance Type: `Free`
3. Environment Variables:
   - `ROOM_CODE` = 비밀 코드 (선택)
   - `UPSTASH_REDIS_REST_URL`, `UPSTASH_REDIS_REST_TOKEN` = 아래 4번에서 복사 (**꼭 추천**)
4. **⚠️ 저장소 설정 (중요)**: Render 무료 서버는 잠들거나 다시 켜질 때 파일이 지워져요. 지은 집과 가방을 지키려면 무료 클라우드 저장소 Upstash를 연결해요.
   1. upstash.com 가입 → **Create Database** (Redis) → 이름 아무거나, Region은 가까운 곳 (예: Singapore 또는 Tokyo)
   2. 만들어진 데이터베이스 화면의 **REST API** 부분에서 `UPSTASH_REDIS_REST_URL`과 `UPSTASH_REDIS_REST_TOKEN` 값을 복사
   3. Render의 Environment에 두 값을 그대로 붙여넣고 저장 → 자동으로 다시 배포돼요
   4. Render 로그에 `☁️ Upstash 클라우드에 저장해요`가 보이면 성공
5. 서버는 15초마다, 그리고 꺼질 때 저장해요.

> 무료 Render는 15분 동안 아무도 없으면 잠들어요. 다음 첫 접속 때 30~60초 기다리면 깨어나요.

## 고쳐보기 쉬운 곳 (`public/shared.js`)

- `SHOP`: 상점 물건과 가격 / `RECIPES`: 만들기 재료
- `CROPS`: 작물 자라는 시간 / `ANIMALS`: 동물이 선물 주는 시간, 사냥 체력
- `QUESTS`: 퀘스트 목표와 보상
- `generateWorld()`: 처음 맵 모양 (맵을 바꾼 뒤에는 `WORLD_VERSION` 숫자를 올리면 새 맵으로 바뀌어요. 기존 건물은 사라져요)
- 탭 이름은 `public/index.html`의 `<title>`과 `public/client.js`의 `BASE_TITLE`
